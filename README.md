# King Roguelike — бета 0.1 (C++ / Qt 6)

Рогалик на шахматном поле **12x12**. Ты играешь за **короля**, который ходит строго
как в обычных шахматах — на 1 клетку в любом направлении. На тебя волнами нападают
**пешки**, появляющиеся из-за верхней границы поля.

## Правила боя
- **Пешки** ходят по шахматным правилам: шаг вперёд (с первого хода — двойной),
  атака — на 1 клетку по диагонали вперёд. Если король стоит под боем пешки — она бьёт (-1 HP).
- **Король**: ход на соседнюю клетку, где есть пешка = **атака**. Наносится урон,
  и пешка **отбрасывается на 2 клетки назад** (от короля). Если HP пешки упал до 0 — она гибнет.
- **Ходы одновременные**: раз в ~450 мс каждая пешка делает свой ход/атаку,
  твои клавиши обрабатываются сразу между тактами.
- Каждые 12 тактов уровень растёт: волна больше, у пешек больше HP. Перебил всех — приходит подкрепление.

## Управление
| Клавиши | Действие |
|---|---|
| W A S D / стрелки | ход (и атака) по ортогоналям |
| Q E Z C | ход (и атака) по диагоналям |
| R | начать заново после смерти |

## Один файл для запуска (Linux Debian x86_64) ⭐
```bash
./build_portable.sh
```
На выходе — **один исполняемый файл** `dist/KingRoguelike` (~29 МБ): self-extracting
архив со встроенными Qt-библиотеками и плагинами платформы. Ставить Qt на целевую
машину НЕ нужно. Просто скопируй его куда угодно и запусти:
```bash
chmod +x KingRoguelike   # если флаг исполнения потерялся при копировании
./KingRoguelike
```
Требуются только стандартные библиотеки, которые есть в любой Debian
(glibc, libstdc++), и X11 (xcb). Тест без дисплея: `QT_QPA_PLATFORM=offscreen ./KingRoguelike`.

## Сборка из исходников
```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j4
./build/KingRoguelike
```
Зависимости: Qt6 Widgets (`sudo apt install qt6-base-dev`).

## Структура
- `src/GameWidget.h/.cpp` — вся логика и отрисовка (поле, HUD, ИИ пешек)
- `src/main.cpp` — точка входа QApplication
