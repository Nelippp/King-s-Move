# SHOTGUN KING style — «Король-стрелок»

Мини-рогалик в духе **Shotgun King: The Final Checkmate**: ты — шахматный Король,
на тебя волнами наступают враги, ходящие по шахматным правилам. Твой ход на клетку
с врагом — это **выстрел из дробовика**: урон + **отбрасывание** (отдача выталкивает
врага прочь). За убийства падают монеты — между волнами работает **лавка дропа**
(новое оружие, патроны, лечение), как карты-дроп в оригинале.

## Как запустить
```bash
pip install pygame
python3 game.py
```

## Правила
- Поле **8×8**. Король ходит на 1 клетку в любом направлении (как в шахматах).
- Враги появляются за краями поля и раз в такт (~0.6 с) делают ход:
  - **♟ Пешка** — шаг вперёд (двойной с дальней позиции), рубит по диагоналям вперёд;
  - **♞ Конь** — прыгает буквой «Г», бьёт с хода;
  - **♜ Ладья** — движется по своей оси и стреляет по прямой, если король на линии.
- Ход короля на занятую клетку = **выстрел**: урон по оружию, враг отлетает на 2–3 клетки.
- **ПРОБЕЛ** — залп по всем соседям сразу (тратит 1 патрон).
- Каждые несколько секунд враги stronger: новая волна толще и злее.
- Перебил волну → открывается **ЛАВКА ДРОППА**, покупки клавишами `1/2/3`,
  `ENTER` — следующая волна.

## Управление
| Клавиши | Действие |
|---|---|
| W A S D / стрелки | ход/выстрел по ортогоналям |
| Q E Z C | ход/выстрел по диагоналям |
| ПРОБЕЛ | залп вокруг себя (патрон) |
| 1 / 2 / 3 | купить молоко / патроны / оружие (в лавке) |
| ENTER | следующая волна (в лавке) |
| R | начать заново |

## Оружие (дроп)
| Пушка | Урон | Особенности | Цена |
|---|---|---|---|
| КУЛАКИ | 1 | только ортогонально | — |
| ОБРЕЗ | 2 | ортогонально | 10 |
| ДРОБОВИК | 2 | все 8 направлений | 20 |
| БОЙНАЯ | 3 | + пробитие насквозь | 35 |
| МАГНУМ .44 | 4 | + пробитие | 55 |
